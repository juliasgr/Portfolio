# 🌿 Portfólio de Certificados

Portfólio pessoal desenvolvido para organizar e apresentar meus certificados acadêmicos e profissionais em um único ambiente, facilitando a visualização das minhas formações e do meu desenvolvimento contínuo.

🔗 **Acesse o projeto:** [portfolio-julia-seger.vercel.app](https://portfolio-julia-seger.vercel.app/)

## ✨ Funcionalidades

- Exibição organizada dos certificados.
- Filtros para facilitar a busca por cursos, instituições e idiomas.
- Layout responsivo e interface intuitiva.
- Design personalizado, com foco na organização e na experiência do usuário.

## 🛠️ Tecnologias utilizadas

- **HTML5** – Estruturação das páginas.
- **CSS3** – Estilização e responsividade.
- **JavaScript** – Funcionalidades e interatividade.
